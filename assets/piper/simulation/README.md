# PiPER Isaac Sim 场景：按实景照片修订

## 当前装配

- 从下到上：**桌面 → 机械臂底座安装法兰 → 黑色长板**。长板压在法兰上，不再垫在机械臂下面。桌面 Z=0.635 m，法兰顶面与长板底面约 Z=0.639 m。
- 黑色长板右端距桌面右沿 **80 mm（8 cm）**。
- 两个黑色 C 型夹具按用户最后提供的局部截图装配：C 型架背部在桌前沿外，上夹口搭在长板上，螺杆压盘从下方顶住桌板。使用包内的可活动 `Clamp.usdc`，替换场景里的静态夹具。螺杆旋转与直线进给联动，名义螺距 3.005 mm/圈；压盘转动和手柄滑动结构保留。
- 全局相机支架在长板右端旁，固定于桌前沿。相机夹具向桌内夹入约 **35 mm**，上夹口与下压盘分别贴住桌板上下表面。
- 全局相机朝工作区内侧：水平方向与桌边约 **30°**，向下俯视约 **30°**。摄像头可见模型与虚拟观察相机一起调整。
- 灯架在桌子与沙发之间，保留原有背景资产。

## 打开与操作

Ubuntu：在本目录执行：

```bash
./start.sh
```

提供桌高、六轴关节、夹爪开合、左右夹具圈数、微波炉门以及空气炸锅抽屉控制。夹具负圈数松开，正圈数拧紧，0 为当前装配接触位置。主视角、局部、全景、全局相机按钮用于切换观察相机。

程序统一推进物理并更新支架弹簧，不要同时点击时间轴 Play 或启动第二个物理循环。仅在 Isaac Sim 中打开 `scene.usda` 可以查看保存的装配；完整控制和弹簧更新请使用启动脚本。

其他安装位置可以设置 `ISAAC_PYTHON`，或将 `ISAAC_SIM_DIR` 指向带 `python.sh` 的安装目录。

无界面局部复核：

```bash
./start.sh --validate
```

## 使用边界

源资产为 Isaac Sim 6.0.1 制作，本机验证版本为 5.1.0。兼容性变换、装配与姿态修改保存在顶层 USD 层；两个原始包中的模型文件未覆盖。

这里完成的是场景装配与局部调试。夹具的 C 型架仍采用固定连接承载，长板与机械臂也保持固定安装；并非完全依靠摩擦夹紧、松开后可自由取走的完整力学系统。螺杆能转动和进给，不等于实际预紧力、摩擦承载或全过程无穿模已经验收。相机朝向按用户指定角度设置，但真实相机内参、外参、手眼标定尚未完成。完整机器人工作空间与抓取任务未测试。

两个原包子目录内的 evidence/checks 属于历史记录，本次证据位于顶层 evidence/。

## 新增任务资产与模型核验

已加入 V4 包内的微波炉、空气炸锅、两只支座、餐盘、四个 25 mm 方块（木、铝、铁、黄铜）和绿色目标区。电器及支座采用明确的固定连接，方块为自由动态物体。V4 表示资产包版本，不是已确认的厂商硬件代号。

已修复九个机器人刚体在 USD 中反向的惯量主轴旋转，并核对 PhysX 实际惯量；8 个活动关节、9 个合并刚体及机器人源网格通过 URDF 比对。修复升降桌空心腿错误的实心碰撞代理，开启自碰撞；背景使用静态碰撞。

- `evidence/audit_summary.json`：38 秒、480 Hz、18239 个物理步的限定范围接触回归，包含升降、局部机械臂运动、夹具、电器开合和落块。
- `evidence/gripper_contact.json`：双指接触诊断块、受阻及松开验证；不是抓取搬运验收。
- `evidence/runtime_fk_comparison.json`：100 组仿真状态与独立 URDF 正运动学比对。
- `URDF_核查报告.md`：官方来源、定制负载、惯量修复、三个真机静止姿态比对和验收边界。

此包仅运行仿真，不包含向真实机器人发送命令的运行路径。真实运动、全空间碰撞、摩擦承载和标定未验收。

可移植性核查：`verify_package.py --root <解压目录>` 重新打开 USD，检查全部依赖在包内、关节目标和电器有效贴图绑定。`SHA256SUMS.json` 用于文件完整性复核。`start.sh --validate --output-dir <证据目录>` 可将复核结果写到其他目录。

场景文件和贴图随包提供；OmniPBR / OmniPBR_Opacity 使用 Isaac Sim 自带的标准 MDL 材质模块，不作为源资产复制。

控制窗口独立浮动并支持滚动，避免小窗口裁掉电器和夹具控制。为兼容本机 Kit 字体，界面采用英文标签：Main=主视角，Detail=局部，Overview=全景，Camera=全局相机，Table height=桌高，Joint=关节，Gripper half opening=单侧夹爪开度，Left/Right clamp=左右夹具圈数，Microwave door=微波炉门角度，Air fryer drawer=空气炸锅抽屉位移。夹具负圈数松开、正圈数拧紧。
