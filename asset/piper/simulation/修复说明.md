# PiPER 最新资产：独立修复版与验收说明

日期：2026-09-26。原始压缩包及服务器原始资产未覆盖。此版本只用于仿真，不连接真机。

## 位置与启动

48 上完整修复目录：

`.`

进入该目录，使用 `bash start_fixed.sh` 打开交互窗口。运行环境为服务器现有 Isaac Sim 5.1 / env_isaaclab_232。

资源紧张时，使用已验证的低分辨率、GPU1 配置：

```bash
cd .
bash start_fixed.sh --config gpu1_validation.json
```

无人值守回归测试：

```bash
bash start_fixed.sh --validate --config gpu1_validation.json --seconds 10
bash start_fixed.sh --validate-training --config gpu1_validation.json --repeats 2 --seconds 3
```

修复入口是 `scene_training.usda` 和 `run_fixed.py`。直接打开原来的 `scene.usda` 或运行 `run_scene.py` 不会应用新修复层。不要只搬走单个 USD 文件；保留整个文件夹的相对目录。

## 本次修改

| 项目 | 修改及边界 |
|---|---|
| 碰撞网格 | 保留 72 个 SDF 碰撞体的凹形表达；相机支架 SDF 分辨率设为 128，其余设为 256，避免原先部分约 1024 的高开销设置。普通凸包限制为 64 顶点。中途尝试的统一凸分解发生不稳定，已撤回，不是交付方案。 |
| 文件引用 | 补齐主机器人 OBJ 对应的 205 份 MTL 及纹理依赖；整理支持入口中的不可移植路径。16 个 URDF 入口的直接网格及 OBJ→MTL→纹理引用闭合验证通过。历史厂商对照资料不作为启动入口。 |
| 实际相机 | 原资产的腕部相机外壳不等于成像传感器；新增跟随 link6 的 WristCamera，保留全局 WorkspaceCamera。提供同步 RGB、深度、内参、世界位姿及有效深度掩码。 |
| 显存与缓存 | 禁用默认多 GPU 联动，GPU 显式配置；使用本副本独立运行缓存，避免写入共享安装目录；12 张超大贴图另生成 2048 分辨率衍生文件，保留原图。未隐藏场景或移除物体。 |
| 可交互物体 | 训练层默认解除盘子对桌面的固定约束，质量保留 237 g；配置 `plate_fixed: true` 可恢复固定。 |
| 控制与复位 | 增加仿真训练接口，动作与真实读回状态分开。关节边界来自本包 URDF。每轮重载完整场景，复位机器人、物体和执行器，不只重置机械臂角度。 |
| 抽屉 | 空气炸锅抽屉阻尼从 10 调为 40 N·s/m，最大关节速度 0.2 m/s；刚度、质量和驱动力上限不变。这是仿真控制调参，不是实物标定结果。 |
| 时间与数据 | 默认物理 480 Hz、控制 30 Hz，每次动作 16 个物理子步；渲染不推进物理时间。逐物理步可记录接触位置、法向、冲量、间隙、控制命令、关节位置/速度和时间。 |
| 错误识别 | 启动日志检查碰撞构建失败、显存不足、非有限状态及异常，避免仅根据窗口正常关闭判断测试成功。 |

物理步沿用本次最新资产的 480 Hz，不是先前 Haply 脚本的 240 Hz；两套任务不可混淆。

## 配置和训练对接

复制 `training_config.json` 写自己的 JSON，使用 `--config 文件路径`；未填写字段继承默认值。

| 字段 | 用途 |
|---|---|
| `gpu` | 渲染和物理使用的 GPU 编号，默认 0；验证配置为 1。需有空闲显存。 |
| `resolution` / `model_resolution` | 原始图像默认 [1280,960]；模型图像默认 [224,224]，保持比例缩放并补边，不能把补边后的内参当成原始内参。 |
| `physics_hz` / `control_hz` | 物理与动作频率，前者须为后者的整数倍。 |
| `home` | joint1～joint8 的初态；前六个单位 rad，后两个滑动关节单位 m。 |
| `head_camera` / `hand_camera` | USD 摄像机路径。 |
| `wrist_local_matrix` | link6 下腕部相机局部矩阵；USD 行向量约定，平移在末行。 |
| `plate_fixed` | 是否把盘子固定到桌面。 |
| `material_overrides` | 按 cube_wood、cube_aluminum、cube_iron、cube_brass、plate 等对象名覆盖已知材质参数。不要根据名字猜摩擦。 |

在创建 SimulationApp 后导入 `TrainingScene`。`reset(seed)` 返回初态；`step(action)` 的 action 为“六个目标关节角 rad + 夹爪总开口 m”，不是末端坐标或关节增量。`observe()` 返回两路图像和读回状态。`record_contacts=True` 时，从 `env.frames` 取逐物理步数据；下一步会清空该列表，采集程序须及时保存。

接触 `impulse_Ns` 是冲量，不是力；除以物理 dt 可得到该步平均接触力，不能称为瞬时峰值力。位置单位 m。关节和相机数据带同一策略时刻；`physics_time_s` 还包含初始静置时间，不能和 `time_s` 混用。

## 仍影响训练，但不能凭空“修复”的事项

1. 部分材质摩擦、相机附加质量/惯量仍是暂定值；需要对应实测值后再覆盖，不能把当前所有物性称为真实标定。
2. 腕部镜头位置、焦距是几何近似，不是实机内参与手眼标定；默认 home 的目标可见性需按任务调整。
3. 升降机构在载荷下仍有约毫米级跟踪偏差；实际关节状态与目标命令必须分开记录。不可用目标位置冒充实测位置，也不宜通过改质量掩盖伺服误差。
4. 本次未进行完整抓取成功率、滑移阈值、负载极限、长期训练、VLA 微调或真机迁移测试。已经提供的是可测试的仿真数据/动作接口，不是已训练策略。
5. 当前场景级 CCD 沿用关闭状态；高速薄壁碰撞、物体跌落等要另行测试，不能从低速短回归推断无穿透。
6. GPU0 的其他仿真批处理曾造成资源竞争；本次没有终止其他人的任务。正式训练需独立资源安排，必要时降低图像分辨率。

历史 `evidence` 中的结果不代表本修复版验收；本版以 `repair_evidence` 下的最终记录为准。失败的中间试验保存在服务器工作目录供追溯，不打包成通过证据。
