## 提交前的三项核验

1. **托管匿名性。** 当前公开 GitHub 页面可见账号和历史入口；本次远端 Git 历史获取遇到连接重置，因此提交作者/邮箱未完成远端验证。更改新提交的用户名不能隐藏已有历史、账号资料、签名与活动。建议使用独立匿名下载入口，并以退出登录的浏览器核查。
2. **再分发权限。** 原始包没有统一的 LICENSE/COPYING 授权文件。需要确认机器人模型、扫描件、纹理、照片等各自的授权范围；第三方来源保留，未自行添加开源授权。
3. **审稿人实际下载与加载。** 下载完整匿名材料并运行完整性检查，确认 LFS 大文件内容存在。当前完成的是静态检查，本次没有运行新的动力学或真实机器人实验。

原始实测和历史仿真证据中的哈希仍描述原实验文件；匿名副本使用新的清单，避免混淆实验记录与包装校验。本次没有上传 GitHub，也没有改动公开仓库或历史提交。
