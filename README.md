# PhysTrace

**A Standardized Benchmark for Evaluating Sim-to-Real Physical Fidelity**

## Overview

PhysTrace is a benchmark for studying physical simulation quality and its relevance to real-world transfer in robot learning. It brings together fundamental physics experiments, everyday interaction tasks, and real-world observations across six simulation platforms.

The benchmark establishes consistent experimental specifications for asset representation, physical properties, initial conditions, loading protocols, and observations. It combines controlled comparisons with process-level tracing to examine physical response accuracy, stability, parameter sensitivity, and the sources of simulation-to-real discrepancies.
